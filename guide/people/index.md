# Модуль people — пнаель "Артонит Сити"

## Назначение

Модуль **people** предоставляет набор сервисов для работы с сотрудниками (контактами).  
## Вызов панели управления
Нажмите на пункт меню "Сотрудники".

### Что предоставляет модуль people:  

| Блок информации | Описание | Где используется |
|------------------|----------|------------------|
| **Поиск** | Поиск сотрудника по буквам фамилии или номеру карты. | `dashboard`<br>`skud`<br>`people` |
| **По категориям доступа** | Просмотр категорий доступа с указанием входящих в них сотрудников. Результат поиска можно соранить в файл для последующей обработки. | `dashboard`<br>`skud`<br>`device_panel` |
| **Просрочнные карты** | Просмотр ФИО с картами, срок действия которых истек. Результат поиска можно соранить в файл для последующей обработки.| `dashboard`<br>`load_order`<br>`device_panel` |
| **Без карты** | Просмотр ФИО, у которых нет карты. Результат поиска можно соранить в файл для последующей обработки.| `dashboard`<br>`system` |

---

## Пользователя не пускает в точку прохода. Порядок действия администратора СКУД.
Открыть меню Сотрудники.  
Ввести фамилию (или часть фамилии) в строку поиска. Нажать кнопку Поиск.  
В форме "Информация сотрудниках" выберите нужную фамили. В результате поиска может быть найдено несколько сотрудников, удовлетворяющих условию поиска.  
В открывшемся окне проверьте раздел События за период. В разделе приведены  события по сотруднику с указанием причины отказа: правильная или ошибочка. Если отказ правильный, то необходимо объяснить сотруднику причину отказа. Если отказ неправильный, то повторить загрузку идентификатора сотрудника в контроллеры СКУД,
